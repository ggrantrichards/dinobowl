# Dino Bowl — AA audit, 2026-08-12

8 specialist finders across sim / flow / animation / special-teams / juice / perf /
meta / hygiene, every finding put through an adversarial verifier that had to
refute it from the code. **64 findings verified → 59 survived (5 refuted).** Line
numbers below are post-verification (the finders' cites were routinely stale by
30-45 lines; verifiers corrected them).

Four items were fixed and DEPLOYED before this document (v35-20260812): the
unguarded-storage boot kill, the first-down rounding bug, the unskippable/overlong
kick flight, and dead cels in `shoved`/`tackled`. See `tests/test_aa_glitchless.js`.

---

## VERDICT

The simulation core really is at/above the AA bar, and pacing now BEATS Retro Bowl
(median whistle-to-snap 0.40-0.63s vs RB's ~1-1.5s). What is not AA is everything
around the core: a **permanent softlock** in the kick input, a **career mode that
deletes its own save** at the end of season one, a **tackle animation whose authored
prone cel expires mid-beat and holds a 90°-rotated standing sprite instead**, and a
long tail of moments-of-truth with no payoff. This is not a game that needs a
redesign — it needs roughly 20 targeted fixes, most of them under 10 lines.

---

## P0 — GLITCHLESS (4 confirmed; ship first, in this order)

**P0-1. Kick input can permanently softlock the game.** `game.js:4722`
`kickLocked()` has no re-entrancy guard and `enterKick` seeds no `k.val`. Two
presses inside one event → `k.acc = k.val - 50` is `NaN` → punt geometry is NaN →
state `kickfly` never completes. Player sees a frozen field, forever, mid-game.
*Fix:* guard on `k.stage`, seed `k.val = 50`, and assert finite geometry in
`launchKick`. *Proof:* harness — double-press the kick, assert state advances.

**P0-2. Career mode deletes itself after its first season.** `game.js:5836-5843`
`hubKey`'s done-branch runs `startOffseason()` for `G.mode === "season"`, then the
NEXT line is an unguarded `if (k === "enter" || k === " ") { clearSeason(); ... }`.
The hub prompt tells you ENTER continues. It wipes the save. *Fix:* `return` after
`startOffseason()`, and make the prompt state what the key does. *Proof:* season →
finish → ENTER → assert `loadSeason()` still returns a season.

**P0-3. `proneT` is never decremented in dead-ball states — so the tackle you
just landed shows a rotated STANDING dino, and `getup` never plays on a routine
tackle.** `game.js:6094-6156`
`tickDeadEntities` ticks `jumpT/spinT/throwT/swingT/catchDiveT/poseT/pileT/
poseChain/fdCeleb` — there is **no `proneT` line**. The authored prone cel expires,
the renderer falls back to the walk sprite still rotated 90°, and it holds for the
rest of the dead beat. This is the single largest cause of "the tackle looks
broken", and it violates LESSON #3 (players must STAND UP). *Fix:* tick `proneT` in
`tickDeadEntities` and route expiry through the `getup` chain. *Proof:* extend
`tests/test_getup.js` to a routine tackle (it currently only covers the first-down
rise path).

**P0-4. SCOUTING renders an empty table on the live host.** `game.js:9241`
`fetch("/api/game/players")` is Flask-only with `.catch(() => { G.scoutData = []; })`,
and `[]` defeats the `if (!G.scoutData)` loading guard — so it fails once, silently,
forever. On football-dino.web.app the screen is simply blank. *Fix:* fall back to
`/game/players.json`; keep `null` on failure so it can retry.

## P1 — SEAMLESS / CORRECT (the bulk; grouped for batching)

**Kick & special teams** (one batch — all touch `resolveKick`/`enterKick`/`onPress`)
- Two mutually-exclusive kick input models fire on the same press: `onPress` calls
  `kickLocked()` (consuming stage 0 with a phantom kick SFX) while the drag release
  resolves at stage 1 — **the aim beat is never a decision.** `5299`, `5320`, `4707`
- Missed FG has no 20-yard floor: a missed chip shot gives the opponent 1st-and-10
  at his own 3. `4828`
- Every extra point snaps from the TD's line of scrimmage — kicker lines up at the
  39 for a "33-yard" XP. `4111` (mechanism confirmed, finder's fix was wrong)
- The one visible kickoff plays over a field with **zero players** — `startKickoff`
  does `G.players = []` and never builds a kick formation. `4616`
- ...and it leaves `ball.mode = "koflight"` + empty `players`, so the first
  play-call card renders a bare field with a football frozen in mid-air. `4635`
- Crowd bed mutes during every kick flight (`inGame` list omits `"kickfly"`), and
  the crowd bus sits ABOVE the SFX bus. `6018`

**Rules & stats correctness**
- **A tie eliminates you from the playoffs and is recorded as a loss for you plus a
  win for the opponent.** `1619` (`const won = G.score.A > G.score.B`)
- **Overtime's banner promises "next score wins" but no scoring path ends the
  game** — OT runs a full timed 5th quarter. `4544`
- Every sack is booked as a QB **rushing attempt** with negative rush yards. `3956`
- `G.szn` is never nulled when leaving the franchise hub, so exhibition/versus/
  online inherit season development, TRAIN, aging and fatigue. `3171`
- `G.stats.rushYds` is never written; TD yardage never reaches `G.stats`. `3945`

**Flow & input**
- `deadElapsed` belongs to the STATE, not the beat, so every *chained* dead beat
  (opening kickoff, END OF Q, HALFTIME, OVERTIME) is skippable on frame 1. `6033`
- The LESSON #4 "0:00 — play runs to the whistle" banner is vetoed whenever any
  other banner is on screen, and never retried. `5991`
- Multi-touch has no primary-pointer concept: a second finger hijacks the slingshot
  anchor and the first lift kills the throw. `1136`
- `netFrame` streams the whole particle array + growing stat map to Firebase
  12×/sec. `903`

**Animation** (relevant to the tackle-quality ask)
- **Hit-stop and slow-mo are discarded at every terminal moment.** `impactMoment`
  accepts `dead`, but the loop does `const scalable = G.state === "live"` then
  `else if (!scalable) { G.freezeT = 0; G.slowT = 0; }` — so the freeze on a
  tackle/sack/INT/TD is thrown away exactly when it should sell the hit. `5939`
- A human defender who dives and misses gets his already-horizontal
  `actionLayFlat` dive cel rotated a **second** 90°. `6541`
- Career bling / QB signature features float 9-11px above the body on prone cels:
  `frameBobDy` measures the bob against the action pack's own cel 0, not the walk
  baseline the head fraction assumes. `8770`
- FB lead block applies an unconditional 0.9s hard freeze, re-armed every 0.35s
  onto the next un-frozen defender (violates LESSON #1 soft-live-contact). `6967`
- `cpuCarrier` rolls juke and stiff-arm **per frame with no dt scaling** — a
  frame-rate-dependent rate bug (LESSON #15). `7483`
- The 0.40s post-catch grace window is checked AFTER the carrier's escape resources
  are spent, so truck/YAC charges and a human's timed stiff-arm are eaten
  silently. `7796`

**Juice gaps**
- `fxConfetti`/`fxFlash` fire only on an offensive TD. A loss plays the scoring
  sting. **The championship is silent.** No FX on a made FG, a pick, or a defensive
  score. `4101`
- Your defense earns no crowd or FX payoff, and the crowd cheers the opponent —
  the only in-play crowd reaction is an offense-A **aww-only** branch. `3845`
- Turf layer redrawn per frame (~840 fillRects of mow grain) though the crowd is
  already cached offscreen. `8317`
- The particle pool from AA_PLUS_PLAN 1.4 never landed — still push + per-frame
  `.filter()`, 17 emitters allocating fresh literals. `8155`
- Anti-aliased vector strokes + an `ellipse` on the turf, violating the stated
  pixel-discipline law. `10033`
- Nothing surfaces `G.lastErr`; `netStatus` reports READY when the Firebase SDK is
  blocked; error UX is seven native `alert()`s. `5953`

## OWNER CALLS

1. **Flask vs static canon** — `/api/game/teams` skips the Madden overlay that the
   shipped `teams.json` has baked in, so the two hosts play different numbers
   (`app.py:356`). *Recommend:* declare Firebase static canonical.
2. **Kickoff spectacle** — the comment promises a boot off the tee with a coverage
   unit; the code empties the field. *Recommend:* build the formation (P1) rather
   than remove the beat, which would undo owner-driven work.
3. **`ballSecurityScore`** — `prior * 50` saturates the 1..100 clamp, making fumble
   hardening an on/off switch (`7971`). *Recommend:* scale to ~12.
